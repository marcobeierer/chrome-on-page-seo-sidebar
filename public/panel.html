How do I enable Chrome Sign-in?
  1. Open Chrome settings.
  2. Turn on Chrome Sign-in.
  3. Sign into Chrome with the Google account that has Search Console access.
  4. Return to this extension and click Connect again.

Signing into a Google website is not enough when Chrome Sign-in is disabled. The extension reads Search Console through the Google account signed into Chrome.

How do I connect Google Search Console?
  1. Open a normal HTTP or HTTPS page from the site you want to check.
  2. Open the Search Console (GSC) tab.
  3. Click Connect.
  4. Choose the Google account that has Search Console access.
  5. Approve the permission request for read-only Search Console access.
Why does it say there are no accessible properties?
  1. Confirm Chrome is signed into the same Google account you use for Search Console.
  2. Open Google Search Console in Chrome and check that the property is visible there.
  3. If the property is missing, ask the property owner to add this Google account.
  4. Return to the extension and click Connect again.
What should I do when no matching property is found?
  1. Check the current page URL shown in the Search Console tab.
  2. Select the Search Console property that contains that exact URL.
  3. Use a domain property or the matching URL-prefix property for this site.
  4. If the property is not listed, verify the site in Search Console for the signed-in Google account.
What should I do when Search Console rate limits requests?
  1. Wait a few minutes before trying again.
  2. Avoid repeatedly clicking Refresh GSC while the error is visible.
  3. Click Refresh GSC after the wait.
